# Visual slop (Impeccable, adapted)

Named layout anti-patterns. Any category. A phrase already in the project's
brief or design.md outranks a list item.

## Kickers and stock labels

- Small label above an h1/h2 (kicker, eyebrow, overline, pill chip)
- How it works, Features, Our story, Get in touch, Why choose us as the only
  heading or as a kicker
- Nav words repeated as the section h2

## Grids and chrome

- Three identical icon + heading + text cards as the page structure
- That equal-card grid repeated in every section
- Nested cards, side-tab accent borders
- Hero-metric template with an invented number
- Product UI chrome (rulers, handles, canvas bed) filling a marketing hero
  unless the brief asked for that shot

## Type and effects

- Italic display headlines
- All-caps tags as decoration
- Gradient text, glass, blur, glow, fake 3D
- Inter / Geist as a default third face
- Extreme pill radii on large surfaces
- Bounce / elastic easing
- Emoji as icons or in headings
- Middle-dot crumb chrome
- Tiny muted paragraphs to fake density

## After a finding

Fix layout here. Do not rewrite headlines for voice — that is copywriting.
