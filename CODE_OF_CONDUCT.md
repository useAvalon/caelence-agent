# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Standards

Examples of behavior that helps:

- Showing empathy and kindness
- Being respectful of differing opinions
- Giving and accepting feedback
- Owning mistakes and learning from them
- Focusing on what is best for the community

Examples of behavior that is not allowed:

- Sexualized language or imagery, or sexual attention
- Trolling, insulting or derogatory comments, and personal or political attacks
- Harassment, public or private
- Publishing others' private information without permission
- Other conduct that would be unprofessional in a workplace

## Enforcement

Report problems to the maintainer through GitHub, [@MadsHaerup](https://github.com/MadsHaerup), or a [private security advisory](https://github.com/useAvalon/caelence-agent/security/advisories/new) when the report should stay confidential.

The maintainer will review reports and may remove comments, lock threads, or block people who break this standard. Consequences scale with the harm: a warning, a temporary ban, or a permanent ban.

This code of conduct applies in GitHub issues, pull requests, discussions, and any other space this project runs.
