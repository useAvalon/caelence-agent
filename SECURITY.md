# Security

Please report vulnerabilities in private, not as a public GitHub issue.

Use [GitHub Security Advisories](https://github.com/useAvalon/caelence-agent/security/advisories/new). That keeps the report off the public issue tracker until there is a fix.

Include what you hit, how to reproduce it, and the version or commit. Strip API keys, tokens, and session logs.

This project runs tools on the machine it is installed on (`exec`, file writes, git). Reports that assume that model are still welcome when a path bypasses the approval gate, leaks secrets, or lets untrusted input run code the user did not ask for.

We aim to acknowledge a private report within a week.
